Prevention of Unauthorized Tampering in Electric Fence

Type: Group Project – Smart India Hackathon

Duration: September 2025 – October 2025

Project Overview

Developed an IoT-based monitoring system to detect unauthorized tampering in electric fences, addressing a real-world problem statement proposed by the Government of Kerala.

Key Contributions

  • Integrated voltage and current sensors to continuously monitor fence conditions.
  • Detected abnormal voltage and current fluctuations indicating tampering or theft.
  • Implemented GSM-based alerts to notify users in real time.
  • Contributed to hardware design, sensor calibration, and software debugging.

Technologies Used

  • Arduino UNO
  • LM393 Voltage Sensor
  • ACS712 Current Sensor
  • GSM Module
  • Arduino IDE
  • Proteus

Self-Calibrating Multi-Sensor Based Electric Motor Protection System

Status: Ongoing

Duration: January 2026 – Present

Project Overview

Designing a low-cost, adaptive electric motor protection system to prevent damage due to overload, overheating, and dry-run conditions.

Key Contributions

  • Implemented multi-sensor monitoring for real-time motor health assessment.
  • Utilized current and temperature sensors for fault detection.
  • Applied core principles of Mechatronics, Embedded Systems, and Electrical Protection.

Components & Technologies

  • Arduino UNO / ESP32
  • ACS712 Current Sensor
  • LM35 Temperature Sensor
  • Embedded C
